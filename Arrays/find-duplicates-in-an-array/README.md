## [Duplicates in Limited Range Array](https://www.geeksforgeeks.org/problems/find-duplicates-in-an-array/1)

**Difficulty:** Easy  
**Topics:** Arrays  

**Problem Description:**

<p><span style="font-size: 14pt;">Given an array <strong>arr[]</strong> of size<strong> n</strong>, containing elements from the range <strong>1 </strong>to<strong> n</strong>, and each element appears at most <strong>twice</strong>, return an array of all the integers that appears twice.</span></p><p><span style="font-size: 14pt;"><strong>Note:</strong> You can return the elements in any order but the driver code will print them in sorted order.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [2, 3, 1, 2, 3]
<strong>Output: </strong>[2, 3] <strong>
Explanation: </strong>2 and 3 occur more than once in the given array.</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [3, 1, 2] <br><strong>Output: </strong>[]<strong><br>Explanation: </strong>There is no repeating element in the array, so the <span style="box-sizing: inherit;">output is empty.</span></span></pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
