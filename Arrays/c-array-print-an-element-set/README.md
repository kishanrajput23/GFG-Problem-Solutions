## [Find element at a given Index](https://www.geeksforgeeks.org/problems/c-array-print-an-element-set-25933/1)

**Difficulty:** Basic  
**Topics:** Arrays, CPP  

**Problem Description:**

<p><span style="font-size: 18px;">Given an array <strong>arr[]</strong> of integers and an index <strong>i</strong>(0-based index). Return the element present at the index i in the array.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong><span style="font-size: 18px;">Input:</span></strong> i<strong> </strong></span><span style="font-size: 14pt;">= 2 , </span><span style="font-size: 14pt;">arr[] = [</span><span style="font-size: 18px;">10, 20, 30, 40, 50]
<strong>Output:</strong> 30<br><strong>Explanation:</strong> The value of arr[2] is 30 .</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong></span><span style="font-size: 18px;">i = 4</span><span style="font-size: 18px;"> , </span><span style="font-size: 18px;">arr[] = [10, 20, 30, 40, 50, 60, 70]</span>
<span style="font-size: 18px;"><strong>Output: </strong></span><span style="font-size: 18px;">50<br><strong>Explanation:</strong> The value of the arr[4] is 50 .</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:<br></strong>1 ≤ arr.size() ≤ 10<sup>6</sup><strong><br></strong></span><span style="font-size: 18px;">0 ≤ i ≤ arr.size() - 1</span><br><span style="font-size: 18px;">1 ≤ arr[i] ≤ 10<sup>9</sup></span></p>

**Expected Complexities:**

Time Complexity: O(1)  
Auxiliary Space: O(1)
