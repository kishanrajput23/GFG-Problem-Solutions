## [Move All Zeroes to End](https://www.geeksforgeeks.org/problems/move-all-zeroes-to-end-of-array0751/1)

**Difficulty:** Easy  
**Topics:** Arrays  

**Problem Description:**

<p><span style="font-size: 18.6667px;">Given an array<strong> arr[] </strong>of non-negative integers, move all the zeros to the end of the array while maintaining the relative order of the non-zero elements. Perform the operation in place, without using an extra array.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [1, 2, 0, 4, 3, 0, 5, 0]
<strong>Output:</strong> [1, 2, 4, 3, 5, 0, 0, 0]
<strong>Explanation:</strong> The three zeros are moved to the end while the order of the non-zero elements remains unchanged.
</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [10, 20, 30]
<strong>Output:</strong> [10, 20, 30]
<strong>Explanation:</strong> No change in array as there are no 0s.
</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [0, 0]
<strong>Output:</strong> [0, 0]
<strong>Explanation:</strong> No change in array as there are all 0s.</span></pre><div id="professor_prebid-root"></div>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
