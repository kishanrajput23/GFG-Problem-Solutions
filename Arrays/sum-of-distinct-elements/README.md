## [Sum of Distinct in Array](https://www.geeksforgeeks.org/problems/sum-of-distinct-elements4801/1)

**Difficulty:** Basic  
**Topics:** Arrays  

**Problem Description:**

<p><span style="font-size: 18px;">You are given an array <strong>a</strong><strong>rr</strong>. Find the sum of distinct elements in an array.</span></p><p><span style="font-size: 18px;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [1, 2, 3, 4, 5]
<strong>Output: </strong>15
<strong>Explanation:</strong> Distinct elements are 1, 2, 3, 4, 5. So sum is 15.</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [5, 5, 5, 5, 5]
<strong>Output:</strong> 5
<strong>Explanation: </strong>Only Distinct element is 5. So sum is 5.</span></pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(n)
