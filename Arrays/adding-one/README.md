## [Adding One to Array](https://www.geeksforgeeks.org/problems/adding-one2529/1)

**Difficulty:** Easy  
**Topics:** Arrays  

**Problem Description:**

<p><span style="font-size: 18px;">Given a non-negative integer(without leading zeroes) represented as an array <strong>arr</strong>. Your task is to add <strong>1</strong> to the number (increment the number by 1). The digits are stored such that the most significant digit is at the starting index of the array.</span></p><p><span style="font-size: 18px;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [5, 6, 7, 8]
<strong>Output:</strong> [5, 6, 7, 9]
<strong>Explanation:</strong> 5678 + 1 = 5679</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [9, 9, 9]
<strong>Output:</strong> [1, 0, 0, 0]
<strong>Explanation:</strong>&nbsp;999 + 1 = 1000
</span></pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
