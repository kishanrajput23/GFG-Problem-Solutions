## [Remove Duplicates from Array](https://www.geeksforgeeks.org/problems/remove-duplicates-in-small-prime-array/1)

**Difficulty:** Easy  
**Topics:** Arrays, Hash, Prime Number  

**Problem Description:**

<p><span style="font-size: 18px;">Given an array <strong>arr[] </strong>consisting of positive integers, return the array by removing all duplicate numbers.</span></p><p><strong><span style="font-size: 18px;">Example:</span></strong></p><pre><strong><span style="font-size: 18px;">Input</span><span style="font-size: 18px;">:</span></strong><span style="font-size: 18px;"> arr[] = [2, 2, 3, 3, 7, 5] <br><strong>Output: </strong>[2, 3, 7, 5]<br></span><span style="font-size: 18px;"><strong>Explanation: </strong>After removing the duplicates 2 and 3 we get 2 3 7 5.<br></span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [1, 2, 3, 4, 5] </span><br><span style="font-size: 14pt;"><strong>Output: </strong>[1, 2, 3, 4, 5]<br><strong>Explanation:</strong> There doesn't exists any duplicate element.</span></pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
