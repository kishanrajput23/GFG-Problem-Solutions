## [Count Zeros in a Sorted Matrix](https://www.geeksforgeeks.org/problems/count-zeros-in-a-sorted-matrix/1)

**Difficulty:** Basic  
**Topics:** Searching, Matrix  

**Problem Description:**

<p><span style="font-size: 18px;">Given a <strong>n * n </strong>binary Square Matrix where each row and column of the matrix is sorted in ascending order. Find the total number of <strong>zeros</strong> present in the matrix.</span></p><p><span style="font-size: 18px;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[0,0,0], [0,0,1], [0,1,1]]<br><strong><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927501/Web/Other/blobid2_1777705528.png" width="157" height="136"> <br>Output: </strong>6
<strong>Explanation: 
</strong>The first, second and third row contains 3, 2 and 1
zeroes respectively.</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1,1], [1,1]]<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927501/Web/Other/blobid1_1777705500.png" height="100"> <br><strong>Output: </strong>0
<strong>Explanation:
</strong>There are no zeroes in any of the rows.</span></pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
