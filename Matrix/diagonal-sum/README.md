## [Diagonal Sum in Matrix](https://www.geeksforgeeks.org/problems/diagonal-sum0158/1)

**Difficulty:** Basic  
**Topics:** Matrix  

**Problem Description:**

<p><span style="font-size: 18px;">Given a square matrix of size <strong>n</strong><strong>×n</strong>. Your task is to calculate the sum of its diagonals.</span></p>
<p><span style="font-size: 18px;"><strong>Note :&nbsp; </strong>When n is odd, there is center value which&nbsp;is counted twice in the diagonal sum.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, 0, 1], [0, 1, 0], [1, 0, 1]]<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927497/Web/Other/blobid5_1777722491.png" width="168" height="146"><br><strong>Output: </strong>6</span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, 2], [3, 4]]<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927497/Web/Other/blobid1_1777714129.png" width="146" height="128"> <br><strong>Output: </strong>10</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ n ≤ 100<br>1 ≤ mat[i][j] ≤ 10000</span></p>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
