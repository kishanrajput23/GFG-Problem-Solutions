## [Bitwise OR of Multiples](https://www.geeksforgeeks.org/problems/factor-or-multiple1128/1)

**Difficulty:** Basic  
**Topics:** Bit Magic, Mathematics  

**Problem Description:**

<p dir="ltr">Given an array <strong><strong>arr[]</strong></strong> comprising of n positive integers and an integer <strong><strong>x</strong></strong>, find the bitwise OR of all multiples of x present in the array.</p>
<p dir="ltr">If no multiple of x is found, the answer should be 0.</p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[]<strong> </strong>= [3, 4, 3, 9], x<strong> </strong>=<strong> </strong>2<br><strong>Output: </strong>4<strong>
Explanation: </strong>Only multiple of 2 in array is 4.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[]<strong> </strong>= [9, 3, 1, 6, 1], x = 3
<strong>Output: </strong>15<strong>
Explanation: </strong>Multiples of 3 in array are 9, 3 and 6. Their OR value is 15.</span>
</pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
