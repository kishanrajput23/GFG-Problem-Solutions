## [One's Complement](https://www.geeksforgeeks.org/problems/ones-complement5928/1)

**Difficulty:** Basic  
**Topics:** Mathematics, Bit Magic  

**Problem Description:**

<p><span style="font-size: 18px;">Given a positive integer <strong>n</strong>, find its one’s complement considering bits from the leftmost set bit to the last bit.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 5
<strong>Output: </strong>2
<strong>Explanation: </strong>Binary of 5 is 101, 1's complement of 101 is 010, 010 is 2 in its decimal form. </span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 255
<strong>Output: </strong>0
<strong>Explanation: </strong>Binary of 255 is 11111111, 1's complement of 11111111 is 00000000, 00000000 which is 0 in its decimal form.</span>&nbsp;</pre>
<p><span style="font-size: 20px;"><strong>Constraints:</strong></span><br><span style="font-size: 20px;">1 ≤ n ≤ 10</span><sup><span style="font-size: 16.6667px;">6</span></sup></p>

**Expected Complexities:**

Time Complexity: O(1)  
Auxiliary Space: O(1)
