## [Replace 0 with 1 in Binary](https://www.geeksforgeeks.org/problems/change-bits1538/1)

**Difficulty:** Easy  
**Topics:** Bit Magic, Numbers  

**Problem Description:**

<p data-start="30" data-end="189"><span style="font-size: 14pt;">Given a number <strong>n</strong>, create a new number by replacing every <strong>0</strong> in its binary representation with <strong>1</strong>. Find the difference between the new number and n.&nbsp; </span></p><p><span style="font-size: 18px;"><strong>Examples:</strong> </span></p><pre><span style="font-size: 18px;"><strong>Input:</strong> n =<strong> </strong>8 
<strong>Output: </strong>[7, 15]
<strong>Explanation: </strong>There are 3 zeros in binary representation of 8. Changing them to 1 will give 15. Difference between these two is 7.</span></pre><pre><span style="font-size: 18px;"><strong>Input:</strong> n =<strong> </strong>6 
<strong>Output: </strong>[1, 7]
<strong>Explanation: </strong>There is 1 zero in binary representation of 6. Changing it to 1 will give 7. Difference between these two is 1.</span></pre>

**Expected Complexities:**

Time Complexity: O(log n)  
Auxiliary Space: O(1)
