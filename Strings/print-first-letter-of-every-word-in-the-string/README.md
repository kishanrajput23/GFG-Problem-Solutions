## [First Letter of Every Word](https://www.geeksforgeeks.org/problems/print-first-letter-of-every-word-in-the-string3632/1)

**Difficulty:** Basic  
**Topics:** Strings  

**Problem Description:**

<div class="entry-content">
<p><span style="font-size: 18px;">Given a string <strong>s</strong>, the task is to create a string with the first letter of every word in the string. The string</span> s<span style="font-size: 18px;"> contains lower case English alphabets and its w</span><span style="font-size: 18px;">ords have a single space between them.</span>&nbsp;</p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> s = "geeks for geeks"
<strong>Output:</strong> gfg<br><strong>Explanation: <br></strong>First word starts at index 0, take 'g' <br>After first space, next word starts with 'f'<br></span><span style="font-size: 14pt;">After second space, next word starts with 'g'</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> s = "bad is good"
<strong>Output:</strong> big</span></pre>
<p><span style="font-size: 20px;"><strong>Constraints:</strong><br>1 ≤ |s| ≤ 10<sup>5</sup></span></p>
</div>

**Expected Complexities:**

Time Complexity: O(|S|)  
Auxiliary Space: O(|S|)
