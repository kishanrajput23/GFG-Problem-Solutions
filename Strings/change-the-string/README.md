## [Change the Case based on First Character](https://www.geeksforgeeks.org/problems/change-the-string3541/1)

**Difficulty:** Basic  
**Topics:** Strings  

**Problem Description:**

<p><span style="font-size: 18px;">Given a string <strong>s</strong>, the task is to change the complete string to uppercase or lowercase depending on the case of the first character.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "abCD"
<strong>Output:</strong> "abcd"
<strong>Explanation</strong>: The first letter (a) is lowercase. Hence, the complete string is made lowercase.</span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: s = "Abcd"
<strong>Output:</strong> "ABCD"
<strong>Explanation</strong>: The first letter (A) is uppercase. Hence, the complete string is made uppercase.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1&lt;=|s|&lt;=10<sup>4</sup></span></p>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
