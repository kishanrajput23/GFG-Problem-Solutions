## [Remainder with 7](https://www.geeksforgeeks.org/problems/remainder-with-7/1)

**Difficulty:** Basic  
**Topics:** Strings  

**Problem Description:**

<p><span style="font-size: 14pt;">Given a number as string <strong>n</strong>, return the remainder of the number when it is divided by 7.</span></p>
<p><strong>Examples :&nbsp;</strong></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> n<strong> = "</strong>5" <br><strong>Output: </strong>5<br><strong><strong>Explanation:</strong></strong> Since 5 is less than 7, the remainder when divided by 7 is 5.<br></span></pre>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> n<strong> = "</strong>8"
<strong>Output: </strong>1<br><strong><strong>Explanation: </strong></strong>8 divided by 7 leaves remainder 1<strong><strong>.</strong></strong></span></pre>
<p><strong>Constraints:</strong><br>1 ≤ |n| ≤ 10<sup>5</sup></p>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
