## [Check if divisible by 4](https://www.geeksforgeeks.org/problems/check-if-divisible-by-43813/1)

**Difficulty:** Basic  
**Topics:** Strings, Mathematics  

**Problem Description:**

<p><span style="font-size: 18px;">Given a number in form of a string <strong>s</strong>. Check whether it is <strong>divisible by 4</strong> or not.</span></p>
<p><span style="font-size: 18px;"><strong>Examples :</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "1124"
<strong>Output:</strong> true
<strong>Explanation</strong>: The last two digits of "1124" are 24. Since 24 is divisible by 4, the given number is also divisible by 4. Hence, the output is true.
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: s = "7"
<strong>Output:</strong> false
<strong>Explanation</strong>: As 7 % 4 = 3, the number is not divisible by 4. Hence, the output is false.
</span></pre>

**Expected Complexities:**

Time Complexity: O(1)  
Auxiliary Space: O(1)
