## [Last index of One](https://www.geeksforgeeks.org/problems/last-index-of-15847/1)

**Difficulty:** Basic  
**Topics:** Searching, Strings  

**Problem Description:**

<p class="PDq2pG_selectionAnchorContainer" data-start="216" data-end="313"><span style="font-size: 14pt;">Given a string <strong>s </strong>consisting only of '0' and '1', find the last index at which '1' occurs. If '1' is not present in the string, return -1.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "01001"
<strong>Output: </strong>4
<strong>Explanation: </strong>Last index of&nbsp; 1 in given string is 4.</span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> s =<strong> "</strong>0"
<strong>Output: </strong>-1
<strong>Explanation: </strong>Since, 1 is not present, so output is -1.</span></pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
