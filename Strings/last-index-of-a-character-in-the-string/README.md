## [Last index of a character](https://www.geeksforgeeks.org/problems/last-index-of-a-character-in-the-string4516/1)

**Difficulty:** Basic  
**Topics:** Strings  

**Problem Description:**

<p><span style="font-size: 20px;">Given a string <strong>s</strong> of size <strong>n</strong> and a character <strong>c</strong>, find the last index (0-based indexing) of c in s. If the character is not present, return -1. Both s and c contain only lowercase and uppercase English alphabets.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "Geeks", c = 'e'
<strong>Output:</strong> 2
<strong>Explanation</strong>: The last occurrence of 'e' is at index 2.
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: s = "okiyh", c = 'z'
<strong>Output:</strong> -1
<strong>Explanation</strong>: The character 'z' is not present in the string.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ n ≤ 10<sup>5</sup><br></span></p>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(1)
