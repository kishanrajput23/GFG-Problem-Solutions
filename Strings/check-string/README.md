## [Check if All Characters Same](https://www.geeksforgeeks.org/problems/check-string1818/1)

**Difficulty:** Basic  
**Topics:** Strings  

**Problem Description:**

<p><span style="font-size: 18px;">Given a string, check if all its characters are the same or not.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "geeks"
<strong>Output:</strong> false
<strong>Explanation</strong>: The string contains different character 'g', 'e', 'k' and 's'.</span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: s = "gggg"
<strong>Output:</strong> true
<strong>Explanation</strong>: The string contains only one character 'g'.</span>
</pre>

**Expected Complexities:**

Time Complexity: O(|s|)  
Auxiliary Space: O(1)
