## [Concatenate a List of Characters](https://www.geeksforgeeks.org/problems/convert-a-list-of-characters-into-a-string5142/1)

**Difficulty:** Basic  
**Topics:** Strings  

**Problem Description:**

<p><span style="font-size: 20px;">Given an array <strong>arr[]</strong> of lower case English characters as strings, merge all of them into a string. Note that the size of every string in the input array is 1 only.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">arr[] = ["g", "e", "e", "k", "s", "f", "o", "r", "g", "e", "e", "k", "s"]
</span><strong style="font-size: 18px;">Output: </strong><span style="font-size: 18px;">geeksforgeeks
</span><strong style="font-size: 18px;">Explanation:</strong><span style="font-size: 18px;"> combined all the characters to form a single string.</span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = ["e", "e", "b", "a"]
<strong>Output: </strong>eeba
<strong>Explanation:</strong> combined all the characters to form a single string.</span> </pre>

**Expected Complexities:**

Time Complexity: O(n)  
Auxiliary Space: O(n)
