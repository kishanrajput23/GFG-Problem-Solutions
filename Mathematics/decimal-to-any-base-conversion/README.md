## [Decimal to Any Base Conversion](https://www.geeksforgeeks.org/problems/decimal-to-any-base-conversion2440/1)

**Difficulty:** Basic  
**Topics:** Mathematics  

**Problem Description:**

<p><span style="font-size: 18px;">Given a decimal number n and an integer b representing the target base, convert n into the given base. </span></p>
<p><span style="font-size: 18px;">Return the converted number as a string.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 12, b = 2<strong>
Output: </strong>"1100"<strong>
Explanation: </strong>Converting the decimal number 12 to base 2 gives 1100. Therefore, the output is "1100".</span></pre>
<pre><span style="font-size: 18px;"><span style="font-size: 18px;"><strong>Input: </strong>n = 282, b = 16<strong>
Output: </strong>"11A"<strong>
Explanation: </strong>Converting the decimal number 282 to base 16 gives 11A. Therefore, the output is "11A".</span></span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>2&nbsp;</span><span style="font-size: 18px;">≤</span><span style="font-size: 18px;"> b&nbsp;</span><span style="font-size: 18px;">≤</span><span style="font-size: 18px;">&nbsp;16</span></p>
<p><span style="font-size: 18px;">1 </span><span style="font-size: 18px;">≤</span><span style="font-size: 18px;"> n&nbsp;</span><span style="font-size: 18px;">≤</span><span style="font-size: 18px;">&nbsp;10</span><sup>9</sup> - 1</p>

**Expected Complexities:**

Time Complexity: O(log n)  
Auxiliary Space: O(log n)
