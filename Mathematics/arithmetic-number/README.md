## [Arithmetic Number](https://www.geeksforgeeks.org/problems/arithmetic-number2815/1)

**Difficulty:** Easy  
**Topics:** Mathematics  

**Problem Description:**

<p><span style="font-size: 18px;">Given three integers &nbsp;'<strong>a</strong>' denotes the first term of an arithmetic sequence, '<strong>c</strong>' denotes the common difference of an arithmetic sequence and an integer '<strong>b</strong>'. you need to tell whether 'b' exists in the arithmetic sequence or not.</span></p><p><strong><span style="font-size: 18px;">Examples:</span></strong></p><pre><span style="font-size: 18px;"><strong>Input:</strong> a = 1, b = 3, c = 2
<strong>Output:</strong> true
<strong>Explanation:</strong> 3 is the second term of the sequence starting with 1 and having a common difference 2.</span></pre><pre><span style="font-size: 18px;"><strong>Input:</strong> a = 1, b = 2, c = 3
<strong>Output:</strong> false
<strong>Explanation:</strong> 2 is not present in the sequence.<br></span></pre><pre><span style="font-size: 18px;"><strong>Input:</strong> a = 1, b = 2, c = 4
<strong>Output:</strong> false
<strong>Explanation:</strong> 2 is not present in the sequence.</span></pre>

**Expected Complexities:**

Time Complexity: O(1)  
Auxiliary Space: O(1)
